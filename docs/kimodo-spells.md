# Kimodo spells and animation clips (from Vaibhav's GPU server)

Everything in `passive/public/clips-kimodo/` was generated by Kimodo-G1-RP on the RTX 4090 game server
(`https://kr2vjwse2bhd6t-8000.proxy.runpod.net`), in the `ClipData` format `ClipSource` already reads:
`{fps: 30, qpos: [[36 numbers] per frame], strikes?, loop?}`. Rows are Kimodo's G1 CSV as-is (MuJoCo axes,
root xyz, root quaternion w-first, 29 hinges in Menagerie order).

**Not wired in.** It's a separate folder, so the sim behaves exactly as before. To try it:
`ClipSource.fetch("/clips-kimodo")` instead of `"/clips"`, or copy the entries you want into
`public/clips/index.json` (LayeredSource then prefers them over the SONIC planner, one motion at a time).

## The four spells (`spell.*`)

Videos of each one in the game screen, with its effect: `docs/kimodo-spells/*.mp4` (`keyframes.png` is one
frame of each).

| Clip | Name | Type / kind / effect | Hit (strike `key`) | Kimodo prompt |
| --- | --- | --- | --- | --- |
| `spell.fireball` | Fireball | fire / projectile / ember_orb | frame 20 (0.67 s) | a person turns the body and draws both hands back to the right hip, then twists forward and thrusts both palms out hard |
| `spell.thunder_call` | Thunder Call | lightning / strike / wisp_bolt | frame 42 (1.40 s) | a person throws both arms out wide to the sides, then raises both hands high overhead and swings them down in front |
| `spell.earth_wall` | Earth Wall | physical / defend / earth_wall | frame 53 (1.77 s) | a person presses both palms together in front of the chest, then crouches and slams both palms down onto the ground |
| `spell.spiral_sphere` | Spiral Sphere (shout "rasengan") | ice / melee / spiral_orb | frame 31 (1.03 s) | a person holds the left hand over the open right palm in front of the body, then lunges forward and thrusts the right palm out hard |

- Each spell file carries one `strikes` window (`key` = the server's hit frame, `from`/`to` = key -0.25/+0.2 s).
  Hit frames follow the move's kind: projectiles and palm strikes hit at the fastest push forward, strikes
  from above and ground slams at the fastest drop.
- `spells.json` has the full spec of each (aliases, power, stability, prompt).
- The visual effects (the fire orb, the lightning bolt, the stone wall, the palm sphere) are drawn by the game
  screen (`client/src/render/effects.ts` on `vaibhav/server`); `earth_wall` and `spiral_orb` are new there.

## Caveats (docs/kimodo-g1.md on vaibhav/server has the sources)
- Kinematic only: feet skate a little and hinges can sit up to ~8 deg past the joint limits, so clamp targets.
- The root quaternion's sign can flip between frames; align hemispheres before blending.
- Frame 0 is 1-7 cm off the origin; ClipSource re-bases on frame 0 anyway.

## Making more
No Kimodo install needed. One HTTPS call, about a second (motion only, never a move):
```
curl -s -X POST https://kr2vjwse2bhd6t-8000.proxy.runpod.net/clip -H 'Content-Type: application/json' \
  -d '{"name": "duck_low", "prompt": "a person ducks very low under a punch and springs back up", "duration": 1.2}'
curl -s https://kr2vjwse2bhd6t-8000.proxy.runpod.net/clip/duck_low > duck_low.json   # {id, fps, joint_names, qpos}
```
Prompts: start with "a person" (styles work: "an old person", "a stealthy person"…), body movement only, no periods.
